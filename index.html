Getting connected

  • Your iPhone and TV must be on the same Wi-Fi network (not a guest network).
  • When asked, allow Local Network access (Settings › Instant TV Remote › Local Network).
  • Can't find your TV? Add it by IP address, which you'll find in the TV's network settings.

Pairing by brand

  • Samsung: choose Allow on the TV's pop-up. If you missed it, open Settings › General › External Device Manager › Device Connection Manager and allow "Instant TV Remote".
  • LG: choose Accept on the TV's connection request. If none appears, turn on "LG Connect Apps" in the TV's connection settings (name varies by model).
  • Roku: no pairing needed. If the Roku refuses, set Settings › System › Advanced system settings › Control by mobile apps › Network access to Default.
  • Sony BRAVIA: turn on Settings › Network › Remote device settings › Control remotely, then type the 4-digit PIN the TV shows. A Pre-Shared Key from IP control settings also works.

Turning the TV on

Many TVs can be woken from standby over Wi-Fi once this is enabled on the TV: Samsung › Power On with Mobile, LG › Turn on via Wi-Fi, Sony › Remote start, Roku TVs › Fast TV start.

Supported: Samsung (2016 and later), LG webOS, Roku players and Roku TVs, and Sony BRAVIA. Not affiliated with these companies.
